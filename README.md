# CoolCare 水電空調工程管理系統

針對台灣水電行／機電工程行設計的營運管理系統，涵蓋派工維修、工程專案承攬、估驗計價與保留款、
分包工班發包與扣繳、出工日報點工、工項單價庫、進銷存、報價請款、設備履歷、保養合約、
報驗申報與承裝業證照，並附**公司官網（含線上估價）**與**客戶專區**。

設計對照水電承裝業實務與相關法規：工程合約的追加減帳與期中估驗計價、業主保留款與履約保證金、
所得稅法第 88 條勞務報酬扣繳與二代健保補充保費、台電竣工報驗與用電設備檢驗維護申報、
自來水事業處配管報驗、電器承裝業與自來水管承裝商登記、營業稅 5% 與統一發票、
消保法定型化契約保固、以及冷媒 F-gas 申報（承接空調業務時適用）。

## 三個入口

| 入口 | 網址 | 對象 |
|------|------|------|
| 公司官網 | `/` | 一般訪客、潛在客戶 |
| 員工管理系統 | `/admin.html` | 內部員工 |
| 客戶專區 | `/portal.html` | 既有客戶 |

## 功能

### 公司官網（/）

對外形象網站，**所有內容由後台「官網內容」維護，改完立即生效，不必改程式**。

- 主視覺、關於我們、營業時間與服務地區、承裝業資格展示（證照過期會自動停止顯示）
- 服務項目 — 分工種呈現，可放說明、參考價與照片
- 服務流程 — 步驟圖（來電估價 → 現勘 → 書面報價 → 施工 → 驗收 → 保固）
- 工程實績 — 相簿式案例，點擊開燈箱看施工說明與多張照片；
  **可由內部工程專案一鍵轉出**（客戶名自動只留姓氏、地址自動只留到行政區，且預設不發布，
  讓人先確認過內容再上架）
- 商品資訊 — 品牌與器材型錄；官網不放實價，改放「歡迎來電洽詢」之類的說明
- 最新消息 — 可分類、置頂、設定發布日與下架日
- 常見問題 — 摺疊式問答
- **線上估價** — 需求類別、服務項目、場所類型、地區、預算、希望到場時間、現場照片上傳；
  送出後直接進到後台「線上估價」頁，客服可一鍵轉成客戶與工單
- 手機優先：漢堡選單、底部浮動聯絡列（來電／LINE／線上估價）
- LINE 加好友、Google 地圖、一鍵撥號；瀏覽計數（後台看得到每日流量與人氣頁）

### 員工端（/admin.html）

**每日作業**

- 總覽 — 待派工、進行中工單、今日到場、急件、逾期、完工待請款、未收款、應付廠商、庫存價值、
  官網待處理詢價、進行中工程／未計價餘額／業主保留款／待付工班款；
  今日行程、我的待辦工單、官網新進詢價；到期提醒（保養、合約、設備保固、工程逾期、報驗待辦、
  承裝業換證、技師證照、低於安全庫存）；上線安全檢查（預設密碼與展示提示未清除即警示）
- 派工看板 — 依技師分組指派，拖拉式安排當日行程
- 派工單 — 開單 → 指派技師 → 出發／到場 → 施工（領料即時扣庫存）→ 完工結算 → 客戶手寫簽收 → 轉請款；
  施工前中後照片、保養檢查表（可量測高低壓／電流／出風溫度）、故障原因與後續建議、
  滿意度評分；狀態流轉有規則保護，已結算的單不能倒回去改
- 工單月曆 — 月檢視所有預約
- 線上估價 — 官網詢價的處理台：客服紀錄、狀態流轉（新進／已聯絡／已報價／已成案），
  一鍵轉客戶＋開工單（同電話自動比對既有客戶，不重複建檔）

**工程專案**（水電行與純維修業最大的差別）

- 工程專案 — 以「案」為單位：合約金額、工期、施工進度、履約／保固保證金、保固到期；
  成本自動由三個來源彙總（工單領料材料＋分包計價＋出工工資），即時算出毛利率與預算餘額；
  已發包未計價的金額另外列出，那是躲不掉的未來成本
- 追加減帳 — 工程變更單，**只有業主簽認（狀態＝已核准）才併入合約金額**。
  未簽認就施工事後追不到錢，是水電行最常見的虧損來源，所以系統刻意把簽認欄位做成必經流程
- 估驗計價 — 依累計完成度自動算本期估驗金額（合約總額 ×（本期% － 前期%）），
  自動扣留保留款與其他扣款（業主代購材料、逾期罰款），一鍵開請款單；
  保留款在請款單上以負項明細列出，業主看得懂；驗收後可另開「保留款退還」期別請領
- 分包工班 — 協力廠商建檔（工種、證照、勞保／營造綜合險、配合評等、點工日薪）
- 發包計價 — 發包單（總價包／單價計量／點工）、分期計價、材料扣回與缺失罰款、對工班的保留款
- **勞務扣繳** — 個人工班單次給付達起扣點自動代扣所得稅與二代健保補充保費；
  公司行號則不扣繳、改加計 5% 營業稅一併支付。系統會累計年度給付與已扣繳稅額，
  次年申報扣繳憑單時直接匯出底稿
- 出工日報 — 大工／小工／技師／學徒／臨時工，工數（0.5＝半天）或工時計價、加班另計、
  天氣（雨天停工佐證）、當日施工內容；工資成本自動歸屬到工程專案
- 工項單價庫 — 水電工項的工資／材料單價分列，含對客戶報價單價、內部成本、發包給工班的單價；
  依分類分組像一本單價本，可整批調價（材料漲價或基本工資調整時一次調完），報價時直接帶入

**客戶與設備**

- 客戶 — 基本資料、多個服務地點（樓層／門禁／停車／施工注意）、往來工單、帳務與客戶專區帳號
- 設備履歷 — 客戶端每一台標的物：冷氣、電熱水器、加壓馬達、水塔、淨水設備、配電盤、
  電錶、消防幫浦等；記錄管材與口徑、線徑、無熔絲開關規格、電號水號、冷媒種類與充填量、
  保固到期、上次／下次保養日
- 保養合約 — 週期、年度次數、涵蓋設備、計費方式；到期自動提醒，可一鍵產生到期保養工單
- 報價單 — 可從單價庫帶入工項；成交後轉工單或轉工程專案

**進銷存**

- 庫存查詢、料件主檔（多價別、安全庫存、序號追蹤、冷媒品項標記）
- 採購進貨、銷貨出庫、盤點、廠商管理
- 多倉別：公司倉／工程車／工地暫存；車庫存對應技師
- 成本採移動平均法，出庫寫入成本快照，日後改價不會回頭改動歷史毛利

**帳務**

- 請款單 — 由完工工單開立（可多張併成月結單）、由估驗計價開立，或手動開立
- 收付款登記、應收帳齡分析（催收用）、應付廠商、技師抽成計算與月結算

**法規與證照**

- 報驗申報 — 台電竣工報驗／新設用電、用電設備檢驗維護申報、自來水配管報驗、
  消防查驗、建管室內裝修；記錄送件日、案號、會驗日、不合格原因與複驗日；
  定期申報類可設週期，標記合格時自動推算下次應申報日；公文掃描件可上傳（支援 PDF）
- 公司證照 — 電器承裝業、自來水管承裝商等登記與專任技術員，換證期限提前提醒
- 冷媒管制 — 充填／回收／洩漏／銷毀逐筆留存，環保申報底稿

**管理**

- 官網內容 — 服務項目、服務流程、工程實績（含相簿）、商品、最新消息、常見問題的增修與上下架；
  官網流量與詢價成案率
- 報表匯出 — 20 種報表，每份皆可輸出 **CSV／Excel(.xlsx)／PDF（列印檢視）**：
  工單明細、技師產值、客戶消費排行、庫存清冊、庫存異動、採購、銷貨、應收、應付、設備清冊、
  保養合約、冷媒紀錄、技師抽成、營運月報、工程專案彙總、估驗計價明細、
  **分包計價與扣繳（扣繳憑單底稿）**、出工日報、報驗申報清冊、線上估價詢問
- 公告（可同步顯示於客戶專區）、帳號權限（模組級勾選）、系統設定、稽核軌跡

### 客戶專區（/portal.html）

- 手機號碼登入（預設密碼為手機末 6 碼，首次登入強制改密；連續失敗會暫時鎖定）
- 線上報修、維修進度查詢、我的設備清單、帳單查詢

## 技術

- 後端：Node.js + Express，JWT Cookie 驗證（員工／客戶分離，cookie 不同）
- 資料庫：SQLite（better-sqlite3，零設定；資料檔在 `data/coolcare.db`）
- 前端：原生 JS SPA，無框架、無編譯步驟；官網為獨立的靜態頁＋公開 API
- 報表：內建零相依 `.xlsx` 產生器；PDF 走瀏覽器列印（不綁 headless Chrome，
  自架環境不一定裝得起來）
- 圖片與檔案：multer；**內部檔案與官網素材分開存放**（見下方注意事項）

## 快速啟動

```bash
npm install
npm run seed        # 建立管理員、工項單價庫、官網示範內容
npm start           # http://localhost:3330
```

預設帳號（正式使用前請修改密碼、清除示範資料）：

| 角色 | 入口 | 帳號 | 密碼 |
|------|------|------|------|
| 管理員 | /admin.html | admin | coolcare123 |
| 工務主管 | /admin.html | wang | 123456 |
| 技師 | /admin.html | lin | 123456 |
| 客戶 | /portal.html | 0912345678 | 345678 |

環境變數：`PORT`（預設 3330）、`ADMIN_PASSWORD`（seed 時指定管理員密碼）、
`COOLCARE_BACKUP_MIRROR`（異地備份目錄，預設 `/root/backups/coolcare`，設為空字串可關閉）。

重建乾淨資料庫：刪除 `data/coolcare.db*` 後重新 `npm run seed`（不加 `--demo` 只建管理員、
單價庫與官網內容，不含示範客戶與工單）。

## 上線前必做

1. **系統設定填公司資料** — 公司名稱、統編、電話、地址、匯款帳號。
   官網的「立即來電」「加 LINE」「地圖」按鈕在對應設定為空時不會顯示。
2. **清除展示提示** — 系統設定裡的 `ui_demo_staff`、`ui_demo_portal` 清空，
   否則登入頁會一直顯示測試帳號。總覽頁的「上線安全檢查」會提醒。
3. **修改預設密碼** — admin 仍為 `coolcare123` 時總覽會出現紅色警示。
4. **調整工項單價庫** — 內建 35 筆是**結構範例不是行情**，工料比例可參考，
   金額請依自家成本改；各地行情差異很大。
5. **填入承裝業登記證號** — 「公司證照」頁的兩筆是範本，填入實際證號與有效期限後，
   官網才會正確顯示資格。

## 部署（nginx + pm2）

```bash
pm2 start src/server.js --name coolcare
```

```nginx
server {
    server_name coolcare.example.com;
    location / {
        proxy_pass http://127.0.0.1:3330;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;      # 登入限流與詢價限流靠這個取得真實 IP
        client_max_body_size 15m;                      # 施工照片與官網素材上傳
    }
}
```

備份：系統每日自動備份資料庫到 `data/backups/`（保留 14 份），並鏡像一份到專案目錄外的
`/root/backups/coolcare`（專案目錄被清空時仍保有一份）。仍建議定期把 `data/`、`uploads/`
與 `public/web-media/` 三個目錄備份到異地——自動備份與主資料庫在同一顆磁碟上，防不了磁碟故障。

## 注意事項

- **上傳檔案分兩處，權限不同**：`uploads/`（施工照片、報驗公文、證照掃描）掛了登入驗證，
  只有已登入的員工或客戶讀得到；`public/web-media/`（官網實績與商品圖）是公開的，
  因為官網訪客本來就要看得到。放檔案前請確認放對地方。
- **官網實績會外流客戶資訊**：由工程專案一鍵轉出時，系統已自動把客戶名縮成姓氏、
  地址截到行政區，且預設不發布。發布前請再確認照片裡沒有門牌、車牌或其他可識別資訊。
- 登入有連續失敗鎖定（同帳號失敗 5 次鎖 15 分鐘），未登入端點另有 IP 限流；
  官網線上估價每 IP 每小時上限可於系統設定調整，表單另有蜜罐欄位擋機器人。
- **扣繳稅率與起扣點會逐年調整**，系統不寫死：`wht_rate`、`wht_threshold`、
  `nhi_rate`、`nhi_threshold` 皆在系統設定中，變更後只影響之後新增的計價單，
  已建立的紀錄不受影響。實際申報請以國稅局與健保署當年度公告為準，本系統的試算僅供作業參考。
- 保留款比例、工程保固月數、營業稅率同樣可於系統設定調整，不寫死在程式裡。
- 法遵紀錄有保護規則：已開立請款單的估驗計價不可直接修改（須先作廢請款單）、
  已付款的分包計價不可改金額、已有計價紀錄的工程不可刪除（只能取消結案）、
  已轉工單的報價不可刪除。
- 冷媒 F-gas 申報與工項單價庫為承接空調業務時使用；純水電行用不到的模組可在
  「帳號權限」中不勾選，該員工的側欄就不會出現。
```
